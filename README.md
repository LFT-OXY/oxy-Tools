# oxy-Tools

维护者策展的 AI 工具链目录，以及把目录中的组件装进宿主（Claude Code、Codex）的安装器。

## 这个仓库的两个用途

**目录**——维护者策展的全部条目：

| 在哪 | 是什么 |
|------|--------|
| `skills/` | 本仓库的 skill 的内容，一个 skill 一个目录 |
| `index.json` | skill 清单，本仓库 skill 的唯一登记处 |
| `catalog.json` | 其余条目和用途清单：第三方 Skill、MCP、工具，以及安装器装不了、只给链接的外部项目 |

目录里有五类条目：

| 类型 | 是什么 | 选中之后 |
|------|--------|----------|
| Skill | 内容放在本仓库的 skill：维护者自己写的，或看过之后收进来的 | 安装器把它复制进宿主 |
| 第三方 Skill | 内容留在作者自己仓库里的 skill，目录只登记它在哪个仓库、里面有哪些 skill。**内容直接来自作者：装上的是作者当时的最新版，维护者没有逐版检查** | 安装器在后台调用 `npx skills add` 把它装进宿主 |
| MCP | 一个 MCP 服务器 | 用宿主自己的命令把它的配置写进宿主 |
| 工具 | 靠官方安装命令装上的程序 | 确认后在终端里执行它的官方安装命令，再复核装上了没有 |
| 外部项目 | 安装器装不了的条目：要自行部署的应用、写代码时引用的开发库、供阅读的资源合集 | 只给说明和链接 |

**按用途找。** 本仓库的 skill 都在「推荐」里；其余的条目各归在一个用途下（联网搜索与文档检索、文档处理……一共 10 个，清单在 `catalog.json` 里）。安装器不按类型分：最前面是「推荐」，下面是各个用途；一个用途下各种类型的条目在同一张列表里，可以一次勾选、一起装。

**装到全局或项目。** Skill 和 MCP 可以装到全局（对这台机器上的所有项目生效，缺省），也可以装到项目（只对运行安装器时所在的目录生效）。工具没有这个选择；Codex 的 MCP 只能装到全局。

**安装器**——`cli/` 下发布到 npm 的 `oxy-tools`。它每次运行时从本仓库现拉目录，把选中的 skill、MCP、工具装进宿主；外部项目只列出说明和官方链接。目录不编译进 npm 包，所以增删条目只需要提交本仓库。

## 运行安装器

```bash
npx oxy-tools
```

它在本机起一个网页，并用默认浏览器打开（网页界面）：挑选、确认、看安装进度和结果都在这一页里，可以跨用途一起挑、一次装完。这个网页只有这台机器访问得到。经 SSH 远程连接、Linux 上没有桌面、或浏览器打不开时，它自动改用终端里的菜单（终端界面）；想直接用终端界面就带上 `--terminal`：

```bash
npx oxy-tools --terminal
```

需要 Node.js 22.13 及以上的 22.x 或 23.5 及以上、一个交互式终端，以及已经装好的 Claude Code 或 Codex；用网页界面还要这台机器上有能打开的浏览器。参数、环境变量和它具体做什么，见 [`cli/README.md`](./cli/README.md)。
