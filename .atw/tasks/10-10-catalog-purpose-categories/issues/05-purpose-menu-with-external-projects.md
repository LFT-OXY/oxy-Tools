# 05 — 主菜单按用途进入，混合列表先放外部项目

**What to build:** 用户启动后看到按用途列出的主菜单，每个用途旁边写着条目数。进入一个用途，在新的列表里看到这个用途下的外部项目；勾选并确认后，在这一轮的最后看到它们各自的说明与完整链接，安装器不再替他打开浏览器。Skill、MCP、工具三个旧分组这一张先留在主菜单上，照旧可用。

**Blocked by:** 01, 02
**Status:** ready-for-agent
**Impl:** done

- [x] 先改规范（入口与测试、终端输出；界面设计规范已由 01 改好，实现与它对不上时先改规范）。
- [x] 主菜单上各个用途按用途清单的顺序排列，每行有名称和条目数；条目数与进入后列表里的行数一致。进入后一行都没有的用途不出现。
- [x] 「应用项目」这个旧分组取消；Skill、MCP、工具三个旧分组留在各用途之后，行为不变。
