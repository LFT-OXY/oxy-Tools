## Q29、Q30 之后核对的事实（2026-10-10）

- `skills add --list` 的输出是给人看的带框线文字（名字 + 英文说明）。`--json` **不能与 `--list` 同用**（实测：`The --json flag cannot be combined with --list.`）。
- 真正安装时加 `--json` 能拿到机器可读的结果：`[{ name, status: "installed", source, path, scope, agents, mode }]`，失败时是 `[{ status: "failed", error }]`。它要求同时带 `-y`。
- `claude mcp add` 的 `--scope` 有 `local`、`user`、`project` 三个值（`claude mcp add --help`，Claude Code 2.1.295）。安装器现在写死 `user`。
- `codex mcp add` **没有**范围选项（`codex mcp add --help`，codex-cli 0.162.0）。官方文档（https://developers.openai.com/codex/mcp ）：MCP 配置默认在 `~/.codex/config.toml`，也可以放在项目的 `.codex/config.toml`，**只对受信任的项目生效**；文档没有给出往项目文件里写的命令。
