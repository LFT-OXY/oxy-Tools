**What to build:** 挑选的列表里，所选的宿主在 Skill 和第三方 Skill 上按所选安装范围下的 skill 目录归组，一组一栏：选了 Codex、Pi、omp 中的两个以上时它们合成一栏，栏名把这几个名字照界面上的先后并列（中文「Codex、Pi、omp」，英文 `Codex, Pi, omp`），状态只写一份。MCP 仍是每个宿主一栏、各看各的配置，但不由安装器装 MCP 的宿主（omp）不出栏。两套界面都这样：终端界面是状态栏，网页界面是卡片底部的状态。定法和终端界面四个宿主时的样子见 `prd.md`「四个宿主时的版式」第 1 条——那里的示意是维护者看着选的。
