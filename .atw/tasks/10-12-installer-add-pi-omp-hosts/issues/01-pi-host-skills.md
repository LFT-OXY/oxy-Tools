# 01 — Pi：检测得到，skill 和第三方 Skill 装得进去

**What to build:** 可执行路径上有 `pi` 命令的机器上，安装器认出 Pi 这个宿主，排在 Claude Code、Codex 之后，界面上写「Pi」。只检测到 Pi 时不问装进哪个，直接往里装；检测到不止一个时它和别的宿主一起供勾选，网页界面的开场引导和页面顶上也有它。本仓库的 skill 和第三方 Skill 都能装给 Pi，全局的装进主目录下的 `.agents/skills`，项目的装进项目目录下的 `.agents/skills`——共用 skill 目录，理由见 ADR-0005。状态探测、覆盖前另问、缺省不覆盖，和 Codex 一字不差。第三方 Skill 交给 skills CLI 的 agent 名是 `pi`。

这一张里 Pi 的 MCP 那一栏先照「这个宿主的 MCP 安装器还不装」处理——宿主的接口要先允许一个宿主没有 MCP 配置（omp 最终就是这样，工单 04 用的是同一个口子），MCP 在这样的宿主下写「不支持」、算计划时不出项。Pi 的 MCP 在工单 02 接上。

同时选了 Codex 和 Pi 时同一个 skill 仍会出两项、装两次（落在同一个目录，结果无害）：合成一项是工单 03 的事，这一张不做，也不要为它写会在工单 03 被推翻的测试。
