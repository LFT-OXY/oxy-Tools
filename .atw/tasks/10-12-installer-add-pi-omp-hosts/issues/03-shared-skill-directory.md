# 03 — 共用 skill 目录：只装一次、合成一行、加一句说明

**What to build:** 所选的宿主里有几个在所选安装范围下用的是同一个 skill 目录时（现在是 Codex 和 Pi），同一个 skill 只装一次：本仓库的只下载、只写一次，第三方 Skill 只执行一条 skills CLI 命令。汇总、进度、结果里它各是一行，宿主那一格把这几个宿主的名字照界面上的先后连起来（中文「Codex、Pi」）。覆盖前另问也只问一次；合计的成功、失败、跳过数按行算。列表里的状态仍是每个所选的宿主各一栏，不合并。
