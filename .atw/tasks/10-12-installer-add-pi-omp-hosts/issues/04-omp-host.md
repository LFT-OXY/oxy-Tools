# 04 — omp：检测得到，skill 装得进去，MCP 写「不支持」

**What to build:** 可执行路径上有 `omp` 命令的机器上，安装器认出 omp 这个宿主，排在最后，界面上写「omp」。本仓库的 skill 和第三方 Skill 都能装给 omp，装进共用 skill 目录；skills CLI 不认识 omp，交给它的 agent 名借用 `pi`。同时选了 Codex、Pi、omp 时合成一行「Codex、Pi、omp」。

omp 的 MCP 安装器不装：列表里 omp 那一栏写「不支持」；选了 omp 且列表里有 MCP 时，MCP 那几栏的说明里多一句——中文「安装器装不了 omp 的 MCP：请在 omp 里用 /mcp add 添加」，英文对应，宿主名和添加办法取自宿主适配。只选了 omp 时所有 MCP 不可选，行上的原因是「需要别的 AI Agent」。任何情况下安装器不执行 `omp` 命令，不读也不写 omp 的配置文件。
