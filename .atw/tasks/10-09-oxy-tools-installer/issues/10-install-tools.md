# 10 — 安装工具

**What to build:** 用户勾选工具，安装器在展示并确认之后执行它的官方安装命令，并在结束后核实工具是否真的可用。用户不用自己去翻每个工具的安装文档。

**Blocked by:** 05
**Status:** ready-for-agent
**Impl:** ready

- [ ] `catalog.json` 的工具条目字段：名字、中英文一句话说明、官方链接、可选的"支持的宿主"列表、安装命令（一条默认命令，可按操作系统覆盖，也可把某个系统显式标为不支持）、检查方式（二选一：某个命令在不在可执行路径上，或用户主目录下某个相对路径存不存在）。
- [ ] `catalog.json` 里有工具条目时，主菜单出现该分组；流程是多选 → 汇总确认 → 执行 → 结果，不问装进哪个宿主。
- [ ] 按当前操作系统选用安装命令；当前系统被标为不支持的条目显示为不可选并注明原因。
- [ ] 条目声明了支持的宿主而这些宿主一个都没检测到时，显示为不可选并注明原因。
- [ ] 执行前在汇总里展示将要执行的完整命令，确认后才执行。
- [ ] 执行时命令的输出实时透传给用户。
- [ ] 命令结束后用条目声明的检查方式复核，以复核结果而不是命令的退出状态作为成功与否的依据；命令成功但检查不通过算失败并说明。
- [ ] 列表显示两种状态：未安装、已安装，由检查方式决定。
- [ ] 一项失败不影响其余项。
- [ ] 目录校验命令（如已存在）能校验工具条目。
- [ ] 以上行为都有经主接缝的测试：执行前展示并确认、按操作系统选命令、系统不支持时不可选、命令成功但检查不通过算失败、两种检查方式。
- [ ] UI: 汇总确认 / 两个工具 — 两条完整命令都在输出里。
- [ ] UI: 工具列表 / 当前系统不支持某条 — 该条不可选并写明原因。
- [ ] UI: 界面预览页 / 本工单新增的画面与状态 / 深色与浅色 — 已作为场景加入预览页，且与 `ui-direction.md` 的选定方向一致。
