# 03 — 把 skill 装进 Claude Code

**What to build:** 用户在 skill 分组里勾选一个或多个 skill，确认后安装器把它们装进 Claude Code 的用户级目录，之后在任何项目里都能用。这是第一条完整的安装通路。

**Blocked by:** 02
**Status:** ready-for-agent
**Impl:** ready

- [ ] 以 `claude` 命令是否可用判断 Claude Code 在不在；skill 装到用户主目录下的 `.claude/skills`。
- [ ] skill 列表支持多选；确认前显示汇总（装什么、装到哪），可确认、返回或取消。
- [ ] 按 skill 单独下载，不下载整个仓库：先向 GitHub 查询当前提交及该 skill 目录下的文件列表，再逐个下载，全部钉在同一个提交上；一次运行里安装多个 skill 共用同一次查询。
- [ ] 环境里有 `GITHUB_TOKEN` 时查询带上它；被 GitHub 限流时给出原因和两个出路（稍后再试，或设置访问令牌）。
- [ ] 目录来源是本地目录时，skill 内容也从该本地目录读取。
- [ ] 文件先下载到临时目录，确认其中有 `SKILL.md` 后再整体替换到目标位置；失败或被中断时清理临时目录，目标位置保持原样。
- [ ] 安装完成后在该 skill 目录内写入安装标记，记录名字、版本、来源提交和安装时间；安装器不写任何集中的状态文件。
- [ ] 安装 skill 的动作只接受"条目 + 目标目录"，自身不知道宿主的存在。
- [ ] 一次安装多项时，某一项失败不影响其余项；结束后逐项显示成功或失败及原因，然后回到主菜单。
- [ ] 以上行为都有经主接缝的测试，包括"下载中途失败后目标位置保持原样"。
- [ ] UI: 汇总确认 / 选了两个 skill — 输出里列出每个 skill 将装到的目录。
- [ ] UI: 结果 / 一项成功一项失败 — 两项各有一行，失败的带原因。
- [ ] UI: 界面预览页 / 本工单新增的画面与状态 / 深色与浅色 — 已作为场景加入预览页，且与 `ui-direction.md` 的选定方向一致。
