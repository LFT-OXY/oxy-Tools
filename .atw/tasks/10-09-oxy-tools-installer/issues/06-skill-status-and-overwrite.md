# 06 — skill 的状态与覆盖

**What to build:** 用户在列表里一眼看出每个 skill 在每个宿主下的现状，重装即可更新；而用户自己手动放置的同名目录不会被悄悄替换。

**Blocked by:** 05
**Status:** ready-for-agent
**Impl:** ready

- [ ] skill 在每个宿主下有四种状态：未安装；已安装（本工具装的，显示已装版本）；已安装且与清单版本不同（同时显示两个版本）；已存在但不是本工具装的（目录存在而没有安装标记，或是一个符号链接）。
- [ ] 状态完全来自对目标目录的实时探测，不依赖任何集中的状态文件。
- [ ] 对已安装的 skill 再装一次即整目录替换，并更新安装标记；汇总里注明目录内的本地改动会丢失。
- [ ] 选中"不是本工具装的"条目时，需要在汇总之外单独确认覆盖，默认不覆盖；拒绝后该目录保持原样，其余选中项照常安装。
- [ ] 目标是符号链接时，同意覆盖只替换链接本身，链接指向的原目录不被改动。
- [ ] 以上行为都有经主接缝的测试：四种状态的显示、覆盖已装的、对"不是本工具装的"目录拒绝与同意两种走向、符号链接只替换链接本身。
- [ ] UI: skill 列表 / 四种状态并存 — 每种状态有不同的文字标记，不只靠颜色区分。
- [ ] UI: 汇总确认 / 含覆盖项 — 标出哪些会被覆盖以及本地改动会丢失。
- [ ] UI: 界面预览页 / 本工单新增的画面与状态 / 深色与浅色 — 已作为场景加入预览页，且与 `ui-direction.md` 的选定方向一致。
