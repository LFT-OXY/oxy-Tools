# 07 — 应用项目：浏览与打开链接

**What to build:** 用户浏览维护者推荐的应用项目，选中一个后看到说明并在浏览器里打开它的官方链接，由用户自己按文档安装。

**Blocked by:** 02
**Status:** ready-for-agent
**Impl:** ready

- [ ] `catalog.json` 的应用项目条目字段：名字（组内唯一，字符集与 skill 名相同）、中英文一句话说明、官方链接；按工单 02 的规则校验和跳过。
- [ ] `catalog.json` 里有应用项目条目时，主菜单出现该分组；没有时不出现。
- [ ] 分组内是单选列表，每行是名字和一句话说明。
- [ ] 选中后显示说明和链接文本，并在默认浏览器打开链接；之后可返回列表。
- [ ] 浏览器打不开时不报错，链接文本仍然可见，用户可以自己复制。
- [ ] 该分组不依赖宿主：一个宿主都没检测到时仍可进入。
- [ ] 目录校验命令（如已存在）能校验应用项目条目。
- [ ] 以上行为都有经主接缝的测试：记录到被打开的链接，且链接文本出现在输出里。
- [ ] UI: 应用项目详情 / 选中一项 — 输出里有说明和完整的链接文本。
- [ ] UI: 界面预览页 / 本工单新增的画面与状态 / 深色与浅色 — 已作为场景加入预览页，且与 `ui-direction.md` 的选定方向一致。
