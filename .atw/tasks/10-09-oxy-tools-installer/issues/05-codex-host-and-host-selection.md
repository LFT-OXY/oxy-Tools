## 实现时定下的事（维护者尚未逐条确认）

- 只检测到一个宿主时的告知，放在主菜单上方的一行「注意」：「没有检测到 Codex，已跳过；组件只装进 Claude Code」。它对只用一个宿主的人每次启动都会出现。
- 多选列表上一个都不勾就确认是回到上一步：宿主选择上回主菜单；skill 列表上，问过宿主就回宿主选择（之前勾的还在），没问过才是主菜单。汇总里的「返回修改」回 skill 列表，不重问宿主。
- 同一个 skill 装进两个宿主时各下载一次：安装动作仍只认“条目 + 目标目录”，两处的结果互不影响；代价是体积大的 skill 要下两遍。
- 一个宿主都没检测到时，光标落在「退出」上（现在没有应用项目分组）；光标仍能移到 skill 分组上，按回车进不去，列表下方出一句「注意  这一项现在选不了」。这是交互库的行为，句子和样式换成了自己的。
- 这时的「注意」只写「没有检测到 Claude Code 或 Codex，暂时装不了组件」，没有写「；应用项目仍可浏览」——留给工单 07 在确有应用项目时加上。
- 工单 03 那个只能看的 skill 列表和详情已去掉（`ui-direction.md` 原本就把这件事交给本工单）。
- 界面预览页的场景缺省仍只有 `claude` 一个命令，所以旧场景的主菜单上方都多了那行「注意」；两个宿主的画面是另加的场景。
