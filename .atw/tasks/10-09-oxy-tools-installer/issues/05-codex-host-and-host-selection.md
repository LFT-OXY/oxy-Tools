# 05 — 第二个宿主 Codex 与宿主选择

**What to build:** 用户可以把 skill 装进 Codex，或同时装进 Claude Code 和 Codex。安装器根据机器上实际有哪些宿主来决定问不问、装到哪。

**Blocked by:** 03
**Status:** ready-for-agent
**Impl:** ready

- [ ] 以 `codex` 命令是否可用判断 Codex 在不在；skill 装到用户主目录下的 `.agents/skills`。
- [ ] 宿主以适配的方式组织，每个宿主回答同样的问题（在不在、skill 装到哪个目录）；宿主列表可以追加。
- [ ] 检测到两个宿主时，安装 skill 前出现宿主选择，默认全选；只检测到一个时不问，直接用它。
- [ ] 选了两个宿主时，同一个 skill 被装进两处，各有自己的安装标记；汇总和结果按宿主分别列出。
- [ ] 只检测到一个宿主时，明确告知另一个未被检测到并被跳过。
- [ ] 两个宿主都没检测到时，主菜单上方有一行说明，组件分组不可进入并注明原因。
- [ ] 以上行为都有经主接缝的测试：装进一个宿主、装进两个宿主、缺一个、两个都缺。
- [ ] UI: 选择宿主 / 检测到两个 — 两项都默认勾选。
- [ ] UI: 主菜单 / 一个宿主都没有 — 上方有说明文字，skill 分组显示为不可进入。
- [ ] UI: 界面预览页 / 本工单新增的画面与状态 / 深色与浅色 — 已作为场景加入预览页，且与 `ui-direction.md` 的选定方向一致。
