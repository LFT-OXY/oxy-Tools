# 08 — 安装 MCP（不带 key）

**What to build:** 用户勾选 MCP，安装器替他把配置写进所选宿主的用户级配置，用户不用学每个宿主的配置写法。本工单只处理不需要 API key 的 MCP。

**Blocked by:** 05
**Status:** ready-for-agent
**Impl:** ready

- [ ] `catalog.json` 的 MCP 条目字段：名字、中英文一句话说明、官方链接、可选的"支持的宿主"列表（省略表示全部支持）、连接方式（二选一：本地进程的启动命令和参数，或远程地址的一个网址）。
- [ ] `catalog.json` 里有 MCP 条目时，主菜单出现该分组；流程与 skill 一致：选宿主（两个都在时）→ 多选 → 汇总确认 → 执行 → 结果。
- [ ] 写入一律调用宿主自己的命令，不直接修改宿主的配置文件：Claude Code 指定用户级范围，Codex 用它自己的添加命令；两种连接方式在两个宿主上都能正确拼出命令。
- [ ] 任何外部命令执行前，汇总里展示将要执行的完整命令，确认后才执行。
- [ ] 宿主里已有同名 MCP 时，先用宿主的移除命令删掉再添加。
- [ ] 列表显示三种状态：未配置、已配置、未知。判断方式是只读地查看宿主的用户级配置文件里有没有同名条目；读不了或格式不认识时显示未知，不报错。
- [ ] 条目声明不支持所选宿主时，在该宿主下显示为不可选并注明原因。
- [ ] 实现宿主适配时对照官方文档核实原生 Windows 上本地进程方式是否需要额外的包装写法，并让命令拼装的测试在 Windows 上也通过。
- [ ] 目录校验命令（如已存在）能校验 MCP 条目。
- [ ] 以上行为都有经主接缝的测试：两种连接方式 × 两个宿主记录到的命令、同名已存在时先移除再添加、三种状态、不支持的宿主不可选。
- [ ] UI: 汇总确认 / 一个 MCP 装进两个宿主 — 两条完整命令都在输出里。
- [ ] UI: MCP 列表 / 配置文件读不了 — 状态显示为未知，没有报错。
- [ ] UI: 界面预览页 / 本工单新增的画面与状态 / 深色与浅色 — 已作为场景加入预览页，且与 `ui-direction.md` 的选定方向一致。
