# 09 — 带 API key 的 MCP

**What to build:** 用户安装需要 API key 的 MCP 时，安装器告诉他去哪申请，等他把 key 粘贴回来后随配置写进宿主。key 只出现在宿主自己的配置里。

**Blocked by:** 08
**Status:** ready-for-agent
**Impl:** ready

- [ ] MCP 条目可声明环境变量列表，每项含变量名、是否必填、中英文说明、申请链接；环境变量只适用于本地进程方式，远程地址方式的条目带环境变量时校验不通过。
- [ ] 安装含环境变量的 MCP 时逐个提问，显示说明和申请链接，输入不回显。
- [ ] 必填项留空时跳过该 MCP 并在结果里说明原因，其余选中项照常安装；可选项留空时不传该变量。
- [ ] 同一次运行里同一个变量只问一次，用于所有选中的宿主。
- [ ] key 只作为参数传给宿主的添加命令；安装器不把它写入任何文件。
- [ ] 汇总里展示的命令中，key 的值以占位符显示。
- [ ] key 的值不出现在任何终端输出里，包括结果和错误信息。
- [ ] 以上行为都有经主接缝的测试：必填留空被跳过、可选留空不传、两个宿主只问一次、记录到的命令带着用户输入的值、全部终端输出里不出现该值。
- [ ] UI: 填写 key / 必填项 — 输出里有该变量的说明和申请链接。
- [ ] UI: 汇总确认 / 含 key — 命令里 key 的位置是占位符。
- [ ] UI: 界面预览页 / 本工单新增的画面与状态 / 深色与浅色 — 已作为场景加入预览页，且与 `ui-direction.md` 的选定方向一致。
