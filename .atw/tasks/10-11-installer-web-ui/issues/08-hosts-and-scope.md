# 08 — 选装进哪些宿主、装到全局还是项目

**What to build:** 页面上有「装进哪些 AI Agent」和「装到哪里」两个随时能改的选项。检测到两个宿主时可以勾选装进哪些，只检测到一个时页面直接写明装进它；安装范围在全局与项目之间选，缺省全局，项目那一项写着是哪个目录。改了之后每个条目的状态马上重查；已选的还在，其中变得装不了的留在已选里并写明原因，不算进将安装的项。装到项目时 skill 落在项目目录里。
