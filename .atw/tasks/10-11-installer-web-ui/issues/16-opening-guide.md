# 16 — 开场引导：答完「装进哪些 AI Agent」「装到哪里」才进挑选的页面

**What to build:** 页面第一次打开，开场动画播完不直接收掉，接着在同一个黑底的画面上问「装进哪些 AI Agent」「装到哪里」——开场引导。两样都带着缺省（检测到的全部宿主、全局），用户点一下「开始挑选」就进到挑选的页面；进去之后顶上那一条里的两样就是刚选的，位置和原来一样、照旧能改。答过之后这次运行里不再出现；没答完就刷新的，它还在、改过的选项也还在。只检测到一个宿主时只选安装范围，一个都没检测到时没有开场引导。维护者的原话见 `research/acceptance-feedback.md` 第 1 节；规矩见 `prd.md` 的故事 68–82、「开场引导」一节和「UI and Design」的「开场引导」。

**Blocked by:** None — can start immediately
**Status:** ready-for-agent
**Impl:** ready

- [ ] 先改规范：网页界面的契约补上「开场引导答完了」这个意图和画面状态里「开场引导答过没有」这一项（起初的值、谁来改、换语言不动它、安装器不拿它拦别的意图），以及页面照「开场播过没有」「开场引导答过没有」两样决定画什么的那张表；设计规范的「开场动画」一节补上开场引导的时刻、版式、控件、放不下时的退路、读屏与焦点的规矩。`GLOSSARY.md` 的「界面」一节写进「开场引导」。
- [ ] 开场引导答过没有记在安装器这边，和「开场播过没有」分开：检测到宿主时起初是没答过；一个宿主都没检测到时起初就算答过。「答完了」只是把它记成答过，发几次都一样；里面多带了东西的不照办。
- [ ] 开场引导里选的就是页面顶上那两样：控件发的是已有的选宿主、选安装范围的意图，提问的话是画面状态里已有的那两句。缺省是检测到的全部宿主、全局；至少留一个宿主。选了「项目」时当场写明是哪个目录。只检测到一个宿主时那一行写成「装进 <宿主>」，没有勾选。
- [ ] 页面第一次打开（动画没播过、引导没答过）：动画照原先的时刻播到约第 2.2 秒不淡出，命令、大标志、版本号留在原处，下面出现两行提问和「开始挑选」，第 3 秒之前都到位、可以操作。点了「开始挑选」那一层才淡出，底下的卡片依次浮上来。用户不点就一直停着，没有倒计时。
- [ ] 动画播过了、引导没答过（没答完就刷新、再开一个标签页、系统开了「减少动态效果」）：不播动画，直接是引导静止的样子，改过的选项还在。引导答过了：照原先的规矩（动画没播过就播完淡出，播过了页面直接出现）。
- [ ] 跳过只跳动画：动画播着时点一下或按任意键，画面直接到引导静止的样子；那一下不落到引导的控件上——选项没有变，也没有直接进去。引导的控件在动画那一段里点不到、拿不到焦点。
- [ ] 安装器不拿它拦别的意图：引导没答过时勾选、要汇总照常照办。任务里已有的网页界面的用例**一条都不改**、全部通过，就是凭据。
- [ ] 开场引导是要用户答的：出现后是一个有名字的对话框，焦点进到里面，Tab 只在里面走，底下的页面在它开着时不可操作、也不读给读屏软件；回车落在「开始挑选」上就是确认。动画那一段照旧不读。
- [ ] 页面自己的固定文字（「开始挑选」、旁边那句「进去之后在页面顶上还能改」、对话框的名字）中英各一份；开场引导里没有切换语言。
- [ ] 终端上的 `t`、Ctrl+C、页面全都断开的时限、终端上那个块都不因开场引导而变：引导开着时按 `t` 页面照样改口成「已改用终端界面」。
- [ ] 经主接缝的新增测试（由测试扮演页面）：检测到两个宿主、只检测到一个时第一份画面状态里都是没答过；一个都没检测到时起初就是答过了；发了「答完了」之后推来的和刷新拿到的都是答过了，别的都没变；没答完时改的宿主和安装范围刷新后还在，答完之后装的东西照它落（去掉一个宿主、选项目，装一个本仓库的 skill，看落点）；换语言不动它；没答过时勾选、要汇总照常照办；「答完了」里多带了东西的不照办。
- [ ] 网页界面的预览：加上开场引导的几格（见下面的 UI 几条）；别的场景先替页面把开场引导答掉，和现在替它发「开场播过了」一样。重新生成后每一格都过脚本自己的检查；原有的格子里，除了开场动画「淡出」那一类因时刻改了而变的，画面不变——变了的列出来。

- [ ] UI: 开场引导 / 选了项目 / 1280×800 — 「装到哪里」下面写着是哪个目录，写得全。
- [ ] UI: 开场引导 / 只有一个宿主 / 1280×800 — 写的是「装进 <宿主>」，没有勾选；只有安装范围可选。
- [ ] UI: 开场引导 / 英文界面 / 1024×768 — 两句更长的提问和它们的控件排得下（放不下时上下排），没有滚动条、没有被裁掉的字。
- [ ] UI: 开场引导 / 键盘焦点在里面 / 1280×800 — 焦点那一圈看得见。
- [ ] UI: 开场引导 / 动画被跳过之后、系统开了「减少动态效果」/ 1280×800 — 都是引导静止的样子，和播完动画停下来的那一格一样。
- [ ] UI: 开场动画 / 一个宿主都没检测到 / 1280×800 — 没有开场引导，动画播完直接是挑选的页面（原先的样子）。
- [ ] 在真实的浏览器里手动核对预览拍不到的（临时主目录，做法同 `research/release-check-record.md`，不弹出用户的默认浏览器）：从那一层出现到开场引导可以操作多久（照页面自己的时钟量，不超过 3 秒）；跳过的那一下——用鼠标点、用键盘按各试一次——没有改掉选项、没有直接进去；只用键盘改两样选项并进去，Tab 走不到底下的页面上；引导上改了选项再刷新，引导还在、选项还在、动画没有重播；答完之后刷新、装完一批点「继续挑选」都不再出现。结果记进这张工单。
