# 11 — 关页面、刷新，和改用终端界面

**What to build:** 页面关掉后安装器过 5 秒自己退出；刷新不会让它退出，刷新后回到刷新前的样子；安装中关掉页面，这一批照样装完，结果打在终端上。网页界面开着、还没开始安装时，用户在终端里按 `t` 就改用终端界面：页面显示已改用终端界面，终端从语言提问接着走。

**Blocked by:** 07
**Status:** ready-for-agent
**Impl:** ready

- [ ] 先改规范：网页界面的契约补上生命周期；终端输出补上待命的提问（一种新的提问）；界面设计规范补上那个块的按键提示和网页界面结束时终端上的各一行；入口与测试补上预设应答里「按 t」的用法。
- [ ] 页面第一次连上之前安装器一直等着，不因为没人连而退出。
- [ ] 连上过之后所有页面都断开满 5 秒：空闲时以 0 退出，终端上一行说明；5 秒之内重新连上就当没断过。时限在测试里可以调短。
- [ ] 刷新，或拿着同一个网址再开一个标签页：看到的是当前的状态（所在的用途、勾选、走到哪一步、进度）。
- [ ] 安装中所有页面都断开满时限：这一批装完，结果照终端界面「结果」分区的样子打在终端上，再以 0 退出。
- [ ] 待命是提问器的一种新提问，不另开一条读键盘的路：它画出按键提示（`t` 改用终端界面、Ctrl+C 退出），网页界面那边结束时可以被收回。正式的实现和预设应答的替身都要有；主题盖全，按键提示本地化。
- [ ] 安装进行中待命不在（工具的安装命令要接管终端的输入输出），装完回来。
- [ ] 按 `t`：关掉本机的网页，页面显示「已改用终端界面，请回到终端」；页面上的勾选丢弃；终端上一行说明，然后从语言提问接着走，目录不重读。之后拿着旧网址的请求连不上。
- [ ] 点「完成」、页面关了、改用了终端界面，终端上各有一行说明；待命的那一行不留在半截。
- [ ] 经主接缝的新增测试：没连上过不退出；连上后断开满时限（空闲）；时限内重连；刷新后状态还在；安装中断开——装完、终端上有结果、退出状态 0；按 `t` 之后是语言提问、能照常用终端界面装一个 skill、页面收到已改用终端界面；安装中没有待命；待命时按 Ctrl+C 以 130 退出。
- [ ] 待命的提问用真实的交互库再测一遍：按键提示实际打出来的字、`NO_COLOR` 下不带样式码、整行在 79 列以内。
- [ ] 界面预览页（终端的）加上带按键提示的那个块、三种结束时的那一行；网页界面的预览加上「已改用终端界面」。
- [ ] UI: 结束 / 已改用终端界面 / 1280×800 — 一句说明，页面上没有还能点的操作。
- [ ] 类型检查和全部测试通过；测试在 Node 22.13 上也跑过一遍。
