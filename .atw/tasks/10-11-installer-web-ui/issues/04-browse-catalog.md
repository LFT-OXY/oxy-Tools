# 04 — 在网页界面里逛目录

**What to build:** 网页界面按选定的视觉方向画出来：页面上一直有「推荐」和各个用途（带条目数），选一个就看到它下面的全部条目——组件按类型分开，每条有完整的说明、推荐标记、在每个检测到的宿主下的状态，装不了的写明原因；外部项目另成一处，说明完整、链接可点。这一张还不能装，宿主是检测到的全部、安装范围是全局。

**Blocked by:** 01, 02, 03
**Status:** ready-for-agent
**Impl:** doing

- [x] 先改规范：网页界面的契约补上浏览用到的画面状态和意图（选用途）。
- [x] 立起后面的工单共用的设计基础：选定方向「利落」的颜色、字号、间距，和条目、状态、标记、按钮这些共用的部件，照 `.atw/spec/cli/web-ui-design.md`。跟随系统的深色与浅色。页面上除了状态的词没有彩色；大标志是单色的。
- [x] 版面是三栏：左边用途（一竖列，带条目数），中间条目（卡片，两张一排），右边已选。这一张还不能勾选，右栏先是空状态；宿主和安装范围在中间一栏顶上，这一张里只显示、不能改。
- [x] 开场动画：页面在这次运行里第一次打开时先播约两秒半（敲出 `$ npx oxy-tools`、大标志一行行打出来、淡出、卡片依次浮上来），照设计规范的「开场动画」。它盖在页面上面，不推迟页面连上安装器；点一下或按任意键跳过；刷新、重连不重播（播没播过记在安装器这边，随画面状态告诉页面）；系统开了「减少动态效果」时不播。
- [x] 页面打开时在「推荐」上（它里面有条目时），否则在第一个有条目的用途上；没有条目的用途不出现；数量的数法和终端界面的主菜单一样。
- [x] 组件按类型分开，顺序是 Skill、第三方 Skill、MCP、工具；第三方 Skill 写明内容直接来自作者；带推荐标记的看得出来并排在同类的前面（「推荐」里只按名字）。排法取自共用的部分，不在页面里另写。
- [x] 每个组件在每个检测到的宿主下的状态都写出来，用的词和终端界面一样；状态、不可选的原因由安装器给出，随画面状态发给页面。
- [x] 不可选的组件上直接看得到原因：需要 AI Agent、需要别的 AI Agent、不支持当前系统。一个宿主都没检测到时页面照常能逛，组件都写明「需要 AI Agent」。
- [x] 外部项目与组件分开显示，写明只给链接、不安装；没有勾选框；链接在新标签页打开，不带来源信息。
- [x] 页面上看得到检测到了哪些宿主、目录里有多少条目，以及有几个条目因为格式有误被跳过。
- [x] 全部操作可以只用键盘完成，焦点看得见。
- [x] 经主接缝的新增测试：有「推荐」/ 没有「推荐」时打开在哪；用途的数量与顺序；一个用途下各类型的先后与排序；两个宿主各自的状态；每种不可选的原因各一条；一个宿主都没有；外部项目没有可勾选的标记、带着链接；被跳过的条目数。
- [x] UI: 浏览 / 条目最多的用途、两个宿主 / 1280×800，深色与浅色 — 每条说明完整，没有一处「…」；外部项目和组件一眼分得开；文字与背景的对比看得清。
- [x] UI: 浏览 / 同上 / 1024×768 — 没有横向滚动条。
- [x] UI: 浏览 / 有不可选的条目 / 1280×800 — 原因直接在条目上，不用把鼠标移上去。
- [x] UI: 浏览 / 一个宿主都没有、用途下只有外部项目 / 1280×800 — 各有该有的说明，没有空着的一栏。
- [x] UI: 开场动画 / 第 0.7、1.5、2.4 秒的定格 / 1280×800，深色与浅色 — 依次是敲到一半的命令、打到一半的大标志、正在淡出而底下的卡片正在浮上来；放慢到十分之一看一遍，没有重影和跳动。（放慢是逐格看的：退场那一段每 50 毫秒一格，`screenshots/04-intro-slow-*.png`；没有录连续播放的视频。）
- [x] UI: 开场动画 / 系统开了「减少动态效果」 / 1280×800 — 没有开场，页面直接出现。
- [x] 类型检查和全部测试通过；测试在 Node 22.13 上也跑过一遍。
