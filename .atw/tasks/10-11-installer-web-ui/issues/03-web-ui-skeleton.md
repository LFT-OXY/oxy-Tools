# 03 — 网页界面的骨架：起得来、连得上、守得住、退得出

**What to build:** 打开一个临时的开关运行安装器，它读完目录后在本机起一个只有这台机器能访问的网页，用默认浏览器打开。页面上只有本机信息（检测到哪些宿主、目录里有多少条目）和「完成」按钮。别的网站和别的机器发来的请求都被拒绝；浏览器打不开或网页起不来时，安装器说明一句原因后改用终端界面；点「完成」或在终端按 Ctrl+C 都能正常收场。缺省仍是终端界面——到工单 13 才换。

**Blocked by:** None
**Status:** ready-for-agent
**Impl:** doing

- [x] 先改规范：入口与测试（启动顺序里「定下用哪个界面」这一步、临时开关、链接打开器现在用来打开网页界面、测试架子的新用法）；新立一份网页界面的契约（意图、画面状态、安全上的几道、生命周期），这一张先写它用到的部分。
- [x] 临时开关是环境变量 `OXY_TOOLS_WEB`：非空时用网页界面，否则和现在完全一样。它只在开发期间存在，工单 13 拿掉。
- [x] 用网页界面时终端不问语言，按系统语言或 `--lang` 说话；目录读不了时照旧在终端上出错并以 1 退出，链接打开器没有被调用。
- [x] 本机的网页用 Node 自带的 HTTP 服务，只监听回环地址，端口由系统挑。运行时依赖一个都不加。
- [x] 每次运行一个随机的口令，带在交给链接打开器的网址里。读状态或引起动作的请求不带口令、口令不对的一律拒绝，答复里没有任何状态。
- [x] `Host` 不是回环地址加这个端口的请求被拒绝；改变状态的请求带着别的来源的 `Origin` 时被拒绝；不发任何允许跨来源访问的头。
- [x] 所有答复都不许缓存；页面带内容安全策略，只许加载和连接它自己的来源；页面的静态文件里没有口令、没有指向外面的地址。
- [x] 页面用 TypeScript 写，与安装器共用「意图」和「画面状态」的类型；用 Preact，由 esbuild 打成静态文件放进构建产物。两样都是开发依赖。页面的源码、构建脚本都在 `cli/` 里，构建产物不提交；`npm pack --dry-run` 里看得到页面的静态文件。
- [x] 状态在安装器这边：页面连上后收到整份画面状态（本机信息、目录里有几个条目被跳过），用一条长连接接收后续的变化；刷新或再开一个标签页看到的是同一个状态。
- [x] 「完成」是一个意图：安装器以 0 退出，页面显示可以关掉这一页。终端按 Ctrl+C：以 130 退出，页面发现连接断了，显示安装器已退出。
- [x] 本机的网页起不来，或链接打开器拒绝：终端上一句原因（经呈现层，画法先写进界面设计规范），然后从语言提问接着走终端界面。
- [x] 网页界面开着时终端上有一个块：网页界面已在浏览器打开、网址（整条写在一行上）、Ctrl+C 退出。画法先写进界面设计规范。（`t` 改用终端界面在工单 11。）这一张里页面关掉不会让安装器退出，那也在工单 11。
- [x] 测试架子加一种用法：给一段「在页面上做什么」的脚本，架子打开临时开关，从只记录的链接打开器那里拿到网址，经真实的本机 HTTP 扮演浏览器；不给脚本时走终端界面，现有的测试一条都不改。
- [x] 经主接缝的新增测试：正常路径（打开、收到本机信息、完成、退出状态 0、终端上有那个块、没有语言提问）；不带口令、口令不对、`Host` 不对、别的来源的 `Origin` 各一条；监听的是回环地址；静态文件里没有指向外面的地址、答复带着内容安全策略；链接打开器拒绝、网页起不来各一条；目录读不了时没有打开浏览器；Ctrl+C。
- [x] 界面预览页（终端的）加上网页界面开着时的那个块、两种退回终端界面的原因。
- [x] UI: 骨架页 / 已连上 / 1280×800 — 看得到本机信息和「完成」按钮。这一页的样子先从简，工单 04 照选定的方向重画。
- [x] UI: 骨架页 / 已完成、安装器已退出、口令不对 / 1280×800 — 各有一句说明，页面上没有还能点的操作。
