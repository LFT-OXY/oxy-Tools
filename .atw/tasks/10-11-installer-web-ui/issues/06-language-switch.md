# 06 — 在页面上切换语言

**What to build:** 页面先按系统语言显示（给了 `--lang` 就按它），页面上有中文 / English 的切换。切换后页面上的一切文字都换过来——版式上固定的字、状态、不可选的原因、条目的说明——所在的用途不变。终端上的语言不跟着变。

**Blocked by:** 05
**Status:** ready-for-agent
**Impl:** ready

- [ ] 先改规范：网页界面的契约里写明换语言是一个意图、安装器按新的语言重发画面状态；「说了什么由安装器定」的文字用的是和终端界面同一份中英文案。
- [ ] 换语言之后，安装器发来的画面状态里状态的词、原因、条目和用途的名字与说明都是新的语言；页面自己的固定文字（按钮、栏名、空状态的话）同时换。
- [ ] 所在的用途、此后各工单加进来的勾选和填过的 key 都不因换语言而变（后面的工单各自为自己的状态补一条断言）。
- [ ] 终端上的语言在启动时就定了，页面上换语言不改它。
- [ ] 刷新之后还是换过之后的语言（状态在安装器这边）。
- [ ] 经主接缝的新增测试：系统语言是中文 / 英文时页面的初始语言；`--lang en`；切换后状态的词与原因跟着换、所在的用途不变；终端输出里没有因此多出东西。
- [ ] 预览里加上英文的浏览那一格（最宽的状态词、最长的说明）。
- [ ] UI: 浏览 / 英文、条目最多的用途、两个宿主 / 1280×800 与 1024×768 — 没有被截断或挤出去的文字，切换语言的地方看得见。
- [ ] 类型检查和全部测试通过；测试在 Node 22.13 上也跑过一遍。
