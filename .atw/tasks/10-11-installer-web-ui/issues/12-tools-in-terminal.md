# 12 — 工具：在网页界面里勾选，在终端里装

**What to build:** 工具可以和别的组件一起勾选。汇总里写明它是「执行安装命令」（不列那一行命令）；轮到它时命令照现在的样子在终端里跑（它要接管终端的输入输出），页面写明「这一项正在终端里安装，请看终端」；跑完后页面上有它的结论。目录里现在一个工具都没有，这一张保证以后加了不出问题。

**Blocked by:** 11
**Status:** ready-for-agent
**Impl:** ready

- [ ] 先改规范：安装工具的规范补上网页界面下怎么展示、在哪执行；网页界面的契约补上「正在终端里安装」的进度。
- [ ] 工具只有一个状态（已安装、未安装），不分宿主、不受安装范围影响。不可选的情形与原因和终端界面一样：一个宿主都没检测到、当前系统不支持、它要的宿主一个都没检测到。
- [ ] 汇总里有工具时，它那一项的操作写「执行安装命令」；**页面上不列那一行命令**（维护者 2026-10-11 定的），执行的仍是目录里的那一整行。
- [ ] 执行在最后。轮到工具时终端上是它自己的分区（照现在的画法），命令的输入输出直接接在终端上；这期间终端上没有待命的提问。
- [ ] 页面上这一项的进度写明正在终端里安装、请看终端；命令结束后页面上是结论：成功与否看复核，不看命令的退出状态。
- [ ] 一批里的工具都跑完后，待命的提问回到终端上。
- [ ] 经主接缝的新增测试：一个工具的正常路径（记录到的是整行交给 shell 的那条命令、页面上的进度与结论、终端上有它的分区）；命令非零退出但复核通过 / 命令成功但复核不通过；命令没能起来；每种不可选的原因各一条；和 skill、MCP 混在一批里的先后；记录到的命令是目录里的那一整行，画面状态里没有它。
- [ ] 预览里加上：有工具一段的浏览（含不可选的）、工具在终端里装时的安装中、带工具结论的结果。
- [ ] UI: 安装中 / 轮到工具 / 1280×800 — 这一项明确写着请看终端，和别的「正在装」分得开。
- [ ] 类型检查和全部测试通过；测试在 Node 22.13 上也跑过一遍。
