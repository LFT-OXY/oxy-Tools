# 15 — 左栏的用途列表加高，当前的用途更显眼

**What to build:** 左栏的用途列表每一行高一些，不显得挤、好点中；当前的用途一眼看得出来。维护者验收时（2026-10-12）在真实的页面上看到的：每行约 30px、显得小；当前的用途只是 `#F2F2F2` 压在侧栏底色 `#FAFAFA` 上，分辨不出。原话和现状见 `research/acceptance-feedback.md` 第 2 节，定下的画法见 `prd.md`「UI and Design」的「左栏的用途列表」。这一张只动左栏的用途列表：左栏的宽度、字号、本机信息、切换语言、「推荐」下面那条线，选中的卡片和分段控件里选中的那一格，都不动。

**Blocked by:** None — can start immediately
**Status:** ready-for-agent
**Impl:** done

- [x] 先改规范：网页界面的设计规范里，颜色表加一个只给当前的用途用的底色（深色、浅色各一个值，写明它和侧栏底色的对比度），「抬一档的底色」的用处里去掉「当前的用途」；左栏版式那一条写上每行的高和当前的用途的新画法。（`.atw/spec/cli/web-ui-design.md`：颜色表多一行「当前的用途的底色」和它的变量 `--current`，「抬一档的底色」去掉了当前的用途；「间距与圆角」多一行用途的行；「三栏」里左栏那一条写了行高和新画法；对比度那一段写了 1.20 和 1.31）
- [x] 用途名只占一行的行不低于 36px 高；字号不变（13px）；用途名折成两行的行跟着高，条目数照旧留在第一行的右边。（量到的是正好 36px；折成两行的是 54px，条目数和第一行同高。行高从 1.4 改成了 18px 的整像素——字号没有动，原因见下面放不放得下那一条）
- [x] 当前的用途用那个更深一档的灰底，字照旧是前景色、粗一档。它的底色和侧栏底色的对比度在深色、浅色下都不低于 1.15:1（起点：浅色 `#E6E6E6`、深色 `#26282C`；照真实的画面调，调了就把数写回规范）。不用前景色的底加反白的字，不加竖线。（用的就是起点 `#E6E6E6`、`#26282C`，看过真实的画面认得出，没有再调：浅色 1.20:1，深色 1.31:1）

- [x] 网页界面的预览重新生成：87 格都过脚本自己的检查（两种窗口下没有放不下的地方）。1024×768、英文界面下左栏的十个用途、本机信息和切换语言照旧够得着——放不下时左栏自己滚动，不把哪一样裁掉。（87 格都过。预览的样例左栏只有五行，量不出来；另拿十个用途的样例和仓库里真实的目录量了：1024×768 英文下正好放得下，余量量到是 2.3px；本机信息多一行「注意」时放不下，左栏滚动，滚到底看得到本机信息和切换语言）
