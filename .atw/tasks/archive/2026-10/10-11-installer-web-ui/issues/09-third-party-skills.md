# 09 — 在网页界面里装第三方 Skill

**What to build:** 第三方 Skill 可以和本仓库的 skill 一起勾选、一起确认、一起装。含多个 skill 的让用户当场挑要其中哪几个；汇总里看得到「内容直接来自作者」的提醒（不列将执行的命令）；目标位置已有同名目录的逐项决定覆盖不覆盖。装法、命令、成败怎么判，都和终端界面一样。

**Status:** ready-for-agent
**Impl:** done
