# 04 — 表的栏间隔加到三格

**What to build:** 用户看任何一张表时，栏与栏之间隔三格而不是两格，状态和说明不再挤在一起。所有的表同一个间隔。

**Blocked by:** None
**Status:** ready-for-agent
**Impl:** done

- [x] 先改界面设计规范：「栏宽按内容定」一条里「再加两格间隔」改成三格。然后才改实现。
- [x] 每一栏取这一栏里最长的一格再加三格间隔。用到所有的表：主菜单、三类组件的多选列表、应用项目列表、选择宿主（名字与目录之间）、skill 与 MCP 的汇总、将执行的工具命令（工具名与命令之间）、结果行（名字、宿主两栏）、工具的结论行、帮助里的两栏表。
- [x] 间隔只有一处定义，各张表不各写各的数。
- [x] 说明仍然拿剩下的宽度，过长时用 `…` 截断；名字、状态、路径、命令仍然从不截断。
- [x] 汇总里备注的放法规则不变：每一条都放得下才成一栏，有一条放不下就都另起一行；栏变宽后更常另起一行是预期之内的。
- [x] 键值行（本机信息、注意、原因与下一步）的键仍占 10 列，不受这条影响；按键提示不受影响。
- [x] 正文每行仍在 79 列以内（整条写在一行上的网址和路径除外）。
- [x] 中文与英文界面同一个间隔。
- [x] 现有测试里按两格间隔写死的断言相应改掉；断言文字内容的不受影响。至少有一条经主接缝的测试卡住「相邻两栏之间是三格」。
- [x] UI: 主菜单 / 默认 / 80 列 — 「分组」一栏最长的一格后面恰好三格空白，再是数量。
- [x] UI: skill 多选列表 / 两个宿主 / 80 列 — 名称、两栏状态、说明之间各三格；最长的说明被 `…` 截断，没有超出第 79 列。
- [x] UI: 汇总与结果 / 默认 / 80 列 — 各栏对齐，间隔三格。
- [x] UI: 英文界面 / 主菜单与多选列表 — 同上。
