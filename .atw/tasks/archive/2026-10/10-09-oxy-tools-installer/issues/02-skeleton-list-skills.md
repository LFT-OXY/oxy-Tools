# 02 — 骨架：启动、读目录、列出 skill

**What to build:** 用户在本地运行安装器，它读取目录、进入主菜单，并能列出目录里每个 skill 的一句话说明。这是贯穿"目录来源 → 校验 → 界面"的第一条完整通路，后续每张工单都在它上面加东西。

**Blocked by:** 01
**Status:** ready-for-agent
**Impl:** done

- [x] `cli/` 是一个自成一体的 TypeScript 包：自带包描述文件（仓库根目录不放），能构建、能跑测试、能在本地启动；构建和测试不触及 `skills/` 下的任何文件；要求 Node 22.13 及以上的 22.x，或 23.5 及以上。
- [x] 仓库根新增 `catalog.json`：一个格式版本号（1）和 MCP、工具、应用项目三个空数组，键名依次是 `version`、`mcps`、`tools`、`apps`（维护者 2026-10-09 确认）。`index.json` 不改。
- [x] 安装器的入口接受五样可替换的外部依赖：目录来源、用户主目录、外部命令执行器、提问器、链接打开器。主接缝的测试架子建好：本地样例目录、临时主目录、只记录不执行的命令执行器、按预设应答的提问器。
- [x] 默认从 GitHub 上本仓库 `main` 分支读取 `index.json` 和 `catalog.json`（仅 HTTPS）；可用一个环境变量把目录来源改为本地目录。
- [x] 读取目录时有进行中提示；之后进入主菜单，只列出有条目的分组（此时只有 skill）和退出。
- [x] 进入 skill 分组能看到每个 skill 的名字和一句话说明，并能返回主菜单；此时还不能安装。在某个 skill 上回车，显示它的版本和说明全文，再回到列表（实现时补充，维护者 2026-10-09 确认）。
- [x] 界面和说明按系统语言环境选中文或英文，可用启动参数强制指定。
- [x] 提供查看帮助和版本号的参数。
- [x] 单条条目校验不通过时跳过该条并提示被跳过的数量；会成为文件系统路径的字段拒绝绝对路径、`..` 和空段；不认识的字段被忽略。
- [x] 目录格式版本高于安装器所支持的版本时，提示升级命令并以非零状态退出，不尝试解析。
- [x] 目录读取失败（如断网）时给出说明并以非零状态退出，不显示堆栈。出错说明一律写到标准错误，标准输出被重定向时用户仍然看得到。
- [x] 没有交互式终端时不进入菜单，提示原因并以非零状态退出。
- [x] 任意画面按 Ctrl+C 干净退出。
- [x] 所有终端输出都经过同一个呈现层，按 `ui-direction.md` 选定的方向实现配色、符号、间距、边框和标题区；交互只用该文件选定的现成交互库，不自写控件。
- [x] 环境变量 `NO_COLOR` 存在或输出不是终端时不输出颜色，界面仍然可读。
- [x] 提供一条仅供开发使用的命令，生成界面预览页：经主接缝按预设场景驱动安装器，把真实的终端输出（含样式）渲染成一个离线 HTML 页面，每个画面一格，各有深色和浅色两种终端背景。预览页是生成物，不提交，不随 npm 包发布。
- [x] 启动后最先打出 OXY 大标志，一次运行只出现一次；没有交互式终端时不打印。
- [x] `ui-direction.md`「交互库」一节交给本工单的四件事已处理，结论写回该文件：只装用到的提示子包还是整包；在最低支持的 Node 版本上确认活动行的嵌套样式表现；没有 Unicode 时的退路已作为场景加入界面预览页；`NO_COLOR` 与 `FORCE_COLOR` 同时设置时的处理。后两件要报给维护者过目或定夺，这一步需要维护者在场。
- [x] 本工单的画面（OXY 大标志、加载、主菜单、skill 列表、三种出错提示）已作为场景加入界面预览页。
- [x] 以上行为都有经主接缝的测试；测试断言文字内容，不断言颜色。
- [x] UI: 主菜单 / `catalog.json` 三个数组为空 — 输出里只有 skill 一个分组和退出。
- [x] UI: 出错 / 目录读不到、格式版本过高、无交互式终端 — 各有一段说明原因和下一步的文字，且不出现堆栈。
- [x] UI: 界面预览页 / 本工单的全部画面 / 深色与浅色 — 与 `ui-direction.md` 的选定方向一致。
