# 03 — 启动时问语言

**What to build:** 用户不带 `--lang` 启动安装器，在大标志之后被问的第一件事是界面语言：`中文` 还是 `English`。光标默认停在按系统语言猜出的那一项上，猜对了按一下回车就过；选了哪种，之后的全部画面就是哪种。给了 `--lang` 的人不被问。

**Blocked by:** 01
**Status:** ready-for-agent
**Impl:** ready

- [ ] 先改规范：入口规范里 `--lang` 的行为、语言环境变量的用途、启动顺序；界面设计规范加「语言提问」这个画面（画法见 `ui-direction.md`）；测试架子缺省怎么对待语言提问写进入口规范的测试一节。然后才改实现。
- [ ] 顺序是：大标志 → 语言提问 → 读取目录 → 本机信息 → 主菜单。
- [ ] 提问是单选，文案固定为 `Language / 语言`，两项依次是 `中文`、`English`；这三段字不随界面语言变。
- [ ] 系统语言的判断方法不变（`LC_ALL`、`LC_MESSAGES`、`LANG`，都为空时看系统语言环境）：判断为中文时光标起始在 `中文`，否则在 `English`。
- [ ] 语言提问上的按键提示用系统语言写。
- [ ] 选定之后的一切输出（加载提示、本机信息、菜单、提问、出错说明、目录条目的说明）都用选定的语言，包括选了与系统语言不同的那一项时。
- [ ] 回答后和别的提问一样收成一行留在屏幕上。
- [ ] 带 `--lang zh` 或 `--lang en`（含 `--lang=…` 的写法）启动时不出现语言提问。
- [ ] `--help`、`--version`、参数无法识别、没有交互式终端时不出现语言提问，输出的语言按系统语言，行为与现在相同。
- [ ] 在语言提问上按 Ctrl+C 以 130 退出，没有出错说明和堆栈。
- [ ] 不落盘：运行前后主目录里没有多出安装器自己的配置文件；下一次启动照样问。
- [ ] 入口的签名不变；语言提问用提问器现有的单选，不加新的提示种类，不加依赖。
- [ ] 「画面上是否已经有内容」的状态跨过语言的切换：选完语言后第一个分区标题（如启动后立刻出错）上方的空行照旧。
- [ ] 测试架子缺省替用户在语言提问上按回车（接受光标起始所在的那一项），现有测试的应答序列不用改；专门测语言提问的用例能自己应答。用真实交互库加脚本按键的跑法同样缺省先按一次回车。界面预览页的场景同样处理。
- [ ] 帮助和包的 README（中英各一处）里 `--lang` 的说明改成「缺省时启动后询问」的意思。
- [ ] 经主接缝的测试覆盖上面每一条：第一问是它及两项的字和顺序；两种系统语言下光标的起始位置；选了与系统语言不同的一项后画面的语言；带 `--lang` 不问；四种不问的情况；Ctrl+C；收成一行。
- [ ] UI: 语言提问 / 提问中，系统语言是中文 / 80 列，深色与浅色 — 提问是 `Language / 语言`，光标在 `中文` 上，下面是 `English`；产品名与提问之间恰好空一行。
- [ ] UI: 语言提问 / 提问中，系统语言不是中文 — 光标在 `English` 上，按键提示是英文。
- [ ] UI: 主菜单 / 语言已回答 — `Language / 语言` 收成一行，在本机信息上方。
- [ ] UI: 界面预览页 — 上面三个状态已作为场景加入，深色与浅色都看过。
