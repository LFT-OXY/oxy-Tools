# Triage Labels

各 skill 以五个标准分诊角色来表述。本文件把这些角色映射到本仓库 issue tracker 中实际使用的标签字符串。

| 标准角色          | 本仓库 tracker 中的标签 | 含义                             |
| ----------------- | ----------------------- | -------------------------------- |
| `needs-triage`    | `needs-triage`          | 需要维护者评估该 issue           |
| `needs-info`      | `needs-info`            | 等待报告者补充信息               |
| `ready-for-agent` | `ready-for-agent`       | 已完整说明，可交给无人值守的代理 |
| `ready-for-human` | `ready-for-human`       | 需要人工实现                     |
| `wontfix`         | `wontfix`               | 不会处理                         |

当某个 skill 提到一个角色时（例如"打上可无人值守的分诊标签"），使用本表中对应的标签字符串。

如需改用你实际使用的词汇，编辑"本仓库 tracker 中的标签"一列即可。
